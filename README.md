# ai-social-media-content-automation
[![CI/CD Pipeline](https://github.com/Ridlofalihin/ai-social-media-content-automation/actions/workflows/ci-cd.yml/badge.svg)](https://github.com/Ridlofalihin/ai-social-media-content-automation/actions/workflows/ci-cd.yml)
## Deskripsi
AI Social Media Content Automation merupakan aplikasi berbasis AI yang membantu pengguna menghasilkan caption, hashtag, dan ide konten media sosial secara otomatis.

## Features
- Generate Caption AI
- Generate Hashtag
- Schedule Posting
- Content History

## CI/CD Implementation
Project ini menggunakan:
- GitHub Actions
- Git Flow
- Automated Testing
- Deployment Simulation
